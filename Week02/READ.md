# Week 02 — Enterprise Infrastructure Planning

## Project Overview

This project presents an Enterprise Infrastructure Plan for NovaByte Solutions, a fictional software development startup with 20 employees. The project focuses on planning the company's hardware, software, network infrastructure, system administration roles, security requirements, backup strategy, and future expansion.

## Learning Objectives

Through this project, I practiced:

* Analyzing organizational IT requirements
* Preparing hardware, software, and network inventories
* Designing an enterprise network topology
* Creating technical documentation using Markdown
* Planning infrastructure and security requirements
* Communicating technical recommendations professionally

## Company Scenario

NovaByte Solutions is a fictional software development company with 20 employees distributed among four departments:

| Department             | Employees |
| ---------------------- | --------: |
| Information Technology |         5 |
| Human Resources        |         4 |
| Finance                |         5 |
| Sales                  |         6 |
| **Total**              |    **20** |

The company is starting from scratch and requires computers, servers, networking equipment, internet infrastructure, security controls, and backup systems.

## Hardware Inventory Summary

The proposed infrastructure includes desktop computers, laptops, a server, router, managed switch, printers, UPS units, wireless access points, NAS storage, external backup drives, and monitors.

## Software Inventory Summary

The planned software environment includes Windows 11 Pro, Ubuntu Server, Microsoft Office, Visual Studio Code, Git, GitHub Desktop, VirtualBox, Google Chrome, Microsoft Defender, AnyDesk, and 7-Zip.
